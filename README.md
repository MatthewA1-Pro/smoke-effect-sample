# NOIR FLOW — interactive ink demo

A single-file WebGL2 ink simulation (stable fluids, MacCormack dye advection, vorticity confinement) on warm ivory. Drag to tear the ink; hover to nudge it. `R` resets, `Space` pauses.

Open `index.html` directly, or serve the folder with any static server. Tuning knobs live in the `CONFIG` object at the top of the script.
